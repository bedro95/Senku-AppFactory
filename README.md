# Senku AppFactory ⚡
https://senku-app-factory.vercel.app/
Welcome to **Senku AppFactory** (managed by **Bader Alkorgli**). This is a professional Agent-native system designed to build high-performance applications with a Neon aesthetic.

## 🛠 Project Components
* **App Factory (`/the_factory/`)**: Professional pipeline for building Consumer Mobile Apps (Expo/React Native).
* **Web3 Factory (`/web3-factory/`)**: Specialized system for Tokenized Web Applications and Solana integration.

## ❄️ Features
* **Interactive Senku Agent**: Integrated AI assistant for real-time development.
* **Snow System**: Interactive visual background effects.
* **Neon Theme**: Green/Blue neon interface for all generated apps.

## 🚀 Current Tool in Development
* **Rug Check Tool**: A global scanner for Solana tokens to detect potential scams and liquidity locks.
